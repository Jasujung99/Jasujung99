## 안녕하세요

한국어를 가르치고 사람들과 읽고 이야기하며, 교육 현장에서 실제로 필요한 도구를 직접 만들어 보고 있습니다.

해움한국어를 운영하고 있으며, 성인·이주 배경 학습자를 위한 수업과 발음 점검, 학습 자료를 더 잘 연결하기 위해 **HAEON Korean 웹사이트를 개발하고 있습니다.** 학습자가 문법과 단어를 아는 데서 멈추지 않고, 자신의 생각과 감정, 이야기를 한국어로 자연스럽게 표현할 수 있는 교육을 지향합니다.

웹과 인공지능, 자동화, 정보 설계는 교육을 대신하는 수단이 아니라 사람의 표현과 이해를 돕는 도구라고 생각합니다. 그래서 기능의 화려함보다 실제 쓰임, 선택권, 개인정보 보호, 오래 이어질 수 있는 운영 방식을 중요하게 봅니다.
